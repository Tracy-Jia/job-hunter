# Job Hunter 安装与使用指南

## 这是什么

Job Hunter 是一套**求职自动投递工具**。它帮你做这些事：

- 🔍 在招聘平台上按关键词批量搜索岗位
- 🎯 根据你设定的规则自动筛掉不合适的（排除行业、薪资不够、单休……）
- 📖 逐个打开详情页读完整 JD（职位描述，Job Description）
- ✍️ 针对每条 JD 生成**定制化的招呼语**（不是千篇一律的"期待进一步沟通"）
- 📨 自动发送招呼语
- 📊 每日复盘：谁回了、谁没回、该跟进谁

**它不是什么**：不是"一键海投 500 份"的工具。它投递的数量取决于当天搜出来多少合适的岗位——好岗位就那么多，不比谁投得多。

> ⚠️ **免责声明**：本工具仅供学习研究。自动化操作可能违反招聘平台规定，使用前请自行查阅目标平台用户协议。使用即表示你自行承担全部风险和责任。

## 第一步：安装（5 分钟）

### 1.1 获取文件

**方式 A：从 GitHub 下载（推荐）**

```bash
# 在命令行（PowerShell 或终端）中执行：
git clone https://github.com/Tracy-Jia/job-hunter.git
```

下载后把整个 `job-hunter` 文件夹放到你喜欢的位置（比如桌面或 D 盘）。

**方式 B：从便携包安装**

如果有人直接给了你一个文件夹，把它放到你喜欢的位置就行。

### 1.2 安装 Python 依赖

打开命令行，进入 job-hunter 文件夹：

```bash
cd job-hunter
pip install -r requirements.txt
```

只需要一个依赖：DrissionPage（用于操控浏览器）。安装完成就行。

### 1.3 安装 Claude Code 技能

把 `SKILL.md` 放到 Claude Code 的技能目录：

1. 打开文件资源管理器，在地址栏输入 `%USERPROFILE%\.claude\skills`，回车
   - 如果提示"找不到文件夹"，就输入 `%USERPROFILE%\.claude`，进去后自己新建一个 `skills` 文件夹

2. 在 `skills` 文件夹里新建一个文件夹，命名为 `job-hunter`

3. 把 `SKILL.md` 拖进刚才建的 `job-hunter` 文件夹

4. 关掉 Claude Code 再重新打开（让它识别新的 skill）

> 如果你是 Mac/Linux 用户，路径是 `~/.claude/skills/job-hunter/`。

## 第二步：配置（首次必做）

### 2.1 准备简历

把 `resume.example.md` 复制一份，改名为 `resume.md`，然后把你的简历内容填进去。

```bash
cp resume.example.md resume.md
```

格式不限，但建议包含：个人信息、教育背景、工作经历、项目经验、技能关键词。**这些内容会被 AI 用来生成定制招呼语的证据。**

### 2.2 配置投递规则

把 `config.example.json` 复制一份，改名为 `config.json`：

```bash
cp config.example.json config.json
```

然后用记事本（或任意文本编辑器）打开 `config.json`，修改以下内容：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| `resume_path` | 简历文件路径 | `"./resume.md"` |
| `skills` | 你的技能关键词（用于匹配评分） | `["薪酬核算", "绩效管理", "HRBP", "员工关系"]` |
| `target_roles` | 目标岗位名称 | `["人事经理", "HRBP", "薪酬绩效主管"]` |
| `exclude_keywords` | 排除关键词（标题含这些词的岗位自动跳过） | `["保险", "助贷", "贷款", "理财", "4S", "汽车", "实习", "培训师", "出纳", "客服", "门店"]` |
| `boost_keywords` | 加权关键词（含这些词的岗位加分） | `["HRBP", "薪酬体系", "绩效改革"]` |
| `company_blacklist` | 公司黑名单（含这些词的公司跳过） | `["外包", "劳务派遣"]` |
| `min_score` | 最低匹配分数（低于此分不投） | `60` |
| `near_districts` | 通勤方便的区 | `["杨浦", "虹口", "静安", "黄浦"]` |
| `far_districts` | 通勤远的区（降权但不排除） | `["浦东", "闵行", "松江", "嘉定"]` |
| `browser` | 浏览器配置 | 见下方说明 |

**浏览器配置**：告诉脚本你的浏览器装在哪里。Windows 用户一般不需要改，Mac 用户改成 Chrome 路径。

```json
"browser": {
  "port": 9222,
  "paths": [
    "C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe",
    "D:\\360浏览器\\360ChromeX\\Chrome\\Application\\360ChromeX.exe"
  ]
}
```

### 2.3 启动浏览器（关键步骤）

每次使用 job-hunter 之前，需要用一个特殊的参数启动浏览器，让脚本能连接上它。

**Windows（Chrome）：**
1. 按 `Win+R`，输入：
```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222
```
2. 回车

**Windows（360极速浏览器）：**
1. 按 `Win+R`，输入：
```
"D:\360浏览器\360ChromeX\Chrome\Application\360ChromeX.exe" --remote-debugging-port=9222
```
2. 回车

**Mac：**
```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --remote-debugging-port=9222
```

> 💡 如果你的浏览器路径跟上面不一样，找到你浏览器的安装位置，替换路径部分即可。`--remote-debugging-port=9222` 这个参数不能少。

启动后浏览器窗口会出现。**在浏览器里登录招聘平台**，确保你已经登录好了。

> 💡 脚本也会自动尝试启动浏览器。如果已经手动启动了，脚本会自动连接，不会重复启动。

## 第三步：使用（每次投递流程）

打开 Claude Code，输入 **"帮我投简历"** 或 **"自动投递"** 或 **"job-hunter"**。

Claude 会引导你走完以下 6 步：

### 流程图

```
① 快速扫描  →  ② 规则预筛  →  ③ 深度读JD  →  ④ AI生成招呼语  →  ⑤ 发送  →  ⑥ 复盘
   ~3分钟        ~1秒           ~2分钟/个        Claude分析         自动发送      次日检查
```

### ① 快速扫描（fast scan）

告诉 Claude 你今天想搜哪些关键词，它会用这些词在招聘平台批量搜索。

```
例如："人事经理, HRBP, 薪酬绩效主管, 办公室主任, 总经理助理, 行政经理"

默认 12 个关键词，分 3 批，每批 4 个词间隔搜索（避免触发平台限流）。
```

输出：一个 JSON 文件，包含所有搜到的岗位卡片信息（公司名、岗位名、薪资范围、链接）。

### ② 规则预筛（prefilter）

Claude 会自动运行预筛脚本，根据你的 `config.json` 自动过滤：

- ❌ 标题包含排除关键词的 → 跳过
- ❌ 公司名在黑名单的 → 跳过
- ❌ 薪资低于 15K 的 → 跳过
- ❌ 作息含"单休""大小周"的 → 跳过
- ⚠️ 通勤距离远的 → 标记但不排除
- ✅ 目标岗位匹配的 → 加分排序

输出：一个过滤后的 JSON 文件，按匹配评分从高到低排序。

### ③ 深度读JD（deep scan）

Claude 打开预筛后的 Top N 个岗位的详情页，逐个读取完整的 JD 文本、公司信息、招聘者姓名、通勤距离。

> ⚠️ **注意**：BOSS 直聘的详情页链接大约 2 小时过期。所以扫描、筛选、读 JD、生成招呼语、发送这五个步骤必须在同一次对话中完成，不能隔天做。

输出：一个包含完整 JD 文本的 JSON 文件。

### ④ AI 匹配 + 招呼语生成

Claude 读取每条 JD 文本，对照你的简历，按 `greeting_guide.md` 中的三段式框架逐条生成定制招呼语：

```
定调（一句话让HR知道"这人对了"）
  ↓
举证（挑JD最关注的1-2个点，用具体数字和事实说话）
  ↓
收尾（自然轻量，不用"期待进一步沟通"）
```

每条招呼语控制在 80-120 字，口语但不随意。同时给出匹配度评分（0-100）。

输出：`send_list.json`（包含每条岗位的招呼语、匹配度评分、招聘者称呼）。

### ⑤ 确认 + 发送

Claude 向你展示发送清单摘要。你确认或微调后，执行发送：

```bash
# 先预览（不实际发送）
python boss.py apply -f send_list.json --dry-run

# 逐条确认发送
python boss.py apply -f send_list.json --confirm

# 或自动发送（间隔10秒，模拟人工）
python boss.py apply -f send_list.json --interval 10
```

> 💡 发送间隔建议 10 秒以上，每日投递总量建议不超过 30 个。上午 10:00-11:30 是 HR（人力资源，Human Resources）活跃窗口，投递效果最好。

### ⑥ 每日复盘（可选，次日做）

```bash
# 查看聊天回复状态
python boss.py daily

# 扫描未回复的对话
python boss.py follow --scan

# 发送跟进消息
python boss.py follow --send -f followup_list.json
```

## 你需要知道的重要事项

### ⚠️ URL 时效性

BOSS 直聘的职位详情页链接大约 **2 小时过期**。这意味着：扫描 → 筛选 → 读 JD → 生成招呼语 → 发送，这五个步骤必须在同一次对话中完成。**不要今天扫描明天再发送——链接已经失效了。**

运行 `python boss.py status` 可以查看当前进度，避免重复工作。

### ⚠️ 反爬与账号安全

- 关键词搜索间隔 ≥ 3 秒
- 详情页访问间隔 ≥ 3 秒
- 发送间隔 ≥ 8 秒（建议 10 秒）
- 每日投递总量建议 ≤ 30
- 任何自动化操作都有风险。**建议先用小号测试，确认稳定后再用主号。**

### ⚠️ 关于默认招呼语

BOSS 直聘在建立好友连接时会自动发送一条默认招呼语（"你好，我非常希望能够得到这个岗位的面试机会……"）。**这条是平台自动发的，不是我们写的。** 我们的定制招呼语是第 2 条消息。

所以定制招呼语直接写实质内容就行，不要用"补充一下""另外"这类衔接词——HR（人力资源）已经自动忽略了那条默认消息。

### ⚠️ 跨天使用

如果投递过程中需要暂停或关掉了窗口，下次打开 Claude Code 时：

1. 先运行 `python boss.py status` 查看进度
2. 如果上一次的扫描结果还在有效期内（2小时内），可以从断点继续
3. 如果链接已过期，需要重新扫描

## 常见问题

**Q: 支持哪些招聘平台？**

核心流水线在一线招聘平台上经过数十轮实战验证。`adapters/` 目录下有其他平台的实验性适配器。

**Q: 支持哪些浏览器？**

Chrome / Edge / 360极速 / Brave / Opera 等 Chromium 内核浏览器都支持。Firefox 使用不同的调试协议，暂不支持。

**Q: 会被封号吗？**

任何自动化操作都有风险。本工具在设计上尽量降低风险——所有操作基于 CDP（Chrome DevTools Protocol，Chrome 开发者工具协议，一种浏览器远程调试标准）操控真实浏览器，与手工操作结构上等价；默认发送间隔 10 秒。但我们无法保证平台的反作弊策略不会升级。

**Q: 为什么不直接调 API（应用程序接口，Application Programming Interface）？**

招聘平台的 API 有严格的限流和鉴权机制，且频繁变动。CDP 路线操控真实浏览器，不受 API 限流影响。

**Q: 招呼语是 AI 写的，会不会很假？**

招呼语框架（greeting_guide.md）规定了硬约束：80-120 字、三段式、禁用模板句、数字必须有简历原文对应、角色不升格。这些约束就是为了防止 AI 写出"AI味道"的招呼语。框架本身跟具体模型无关，当前用 Claude 执行，其他中文能力好的模型也能跑。

**Q: Claude Code 说"找不到 job-hunter 技能"？**

检查 SKILL.md 是不是放对了位置：`C:\Users\你的用户名\.claude\skills\job-hunter\SKILL.md`。然后关掉 Claude Code 重新打开。

**Q: 运行脚本时报错"无法连接浏览器"？**

1. 确认浏览器已经用 `--remote-debugging-port=9222` 参数启动了
2. 在浏览器地址栏输入 `http://localhost:9222`，如果能打开一个页面说明端口正常工作
3. 如果端口被占用，换一个端口号（如 9223），同时修改 `config.json` 中的 `browser.port`

**Q: 能批量海投吗？**

技术上可以调大参数，但**强烈不建议**。这不是这个工具的设计思路——用人话说：HR 看到"期待进一步沟通"的第三秒就知道是海投，直接划走。少投、精准投、定制招呼语，回复率更高。

**Q: 我的数据安全吗？**

所有操作在你本地电脑上完成，简历、配置、投递日志都不会上传到任何第三方。`config.json` 和 `resume.md` 已加入 `.gitignore`，不会误传到 GitHub。发送前可以检查：从 `.example` 文件复制的模板不含任何个人信息。

## 换机迁移指南

换了新电脑？按以下步骤迁移：

### 你需要从旧电脑带走的东西

| 文件 | 位置 | 说明 |
|------|------|------|
| `config.json` | `job-hunter/config.json` | 你的投递规则配置 |
| `resume.md` | `job-hunter/resume.md` | 你的简历 |
| 整个 `job-hunter` 文件夹 | 你放的位置 | 或者从 GitHub 重新 clone |

### 在新电脑上的步骤

1. **安装 Python 3.9+**（[python.org](https://www.python.org/downloads/) 下载）
2. **安装 Claude Code**（[claude.ai/code](https://claude.com/claude-code) 下载）
3. **把 `config.json` 和 `resume.md`** 放到 job-hunter 文件夹里
4. **安装 Python 依赖**：`pip install -r requirements.txt`
5. **安装技能**：把 `SKILL.md` 放到 `~/.claude/skills/job-hunter/`
6. **修改浏览器路径**：编辑 `config.json` 中的 `browser.paths`，改成新电脑上浏览器的安装位置
7. 重启 Claude Code，说"帮我投简历"测试

> 💡 如果你是从 GitHub clone 的，`config.json` 和 `resume.md` 不会被 git 跟踪（在 `.gitignore` 里），需要手动从旧电脑拷贝。
